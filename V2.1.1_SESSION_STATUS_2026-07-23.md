## 🎯 Key Patterns Established

### Pattern 1: Required Parameter Validation
```python
if not quote_id or not quote_id.strip():
    raise BritecoreError.MissingParameter("quote_id is required")
```

### Pattern 2: Mutual-Exclusivity Validation
```python
verification_list = [
    {"id": id},
    {"external_system_reference": external_system_reference},
]
priority_list = ["id", "external_system_reference"]
request_json = API_CLIENT.multiple_parameter_verification(verification_list, priority_list)
```

### Pattern 3: Docstring Format
```python
def function_name(param1: str, param2: bool | None = None, **kwargs) -> Any:
    """One-line summary of what the function does.

    Optional multi-sentence description providing context and business logic.

    Args:
        param1: Description of required parameter.
        param2: Description of optional parameter (default: X).
        **kwargs: Additional request parameters (timeout, retry, headers, etc.).

    Returns:
        Description of return value and its structure.

    Raises:
        BritecoreError.MissingParameter: If required param missing.

    Example:
        >>> function_name(param1="value", param2=True)

    POST /api/v2/path/endpoint
    """
```
