*Last updated: July 16, 2026*
*Document type: Comprehensive migration guide*

## Overview

Phase 6 completes the v2.0.0 migration by:

## Breaking Changes in v2.0.0

### ❌ Removed: `britecore_sdk.classes` Module

**What was removed:**
- `britecore_sdk.classes.Quote`
- `britecore_sdk.classes.Contact`
- `britecore_sdk.classes.Policy`
- All other legacy class wrappers

**Migration:**

Before (v1.x):
```python
from britecore_sdk.classes import Quote

quote_obj = Quote(...)
```

After (v2.0.0):
```python
# Option 1: Use typed response model
from britecore_sdk.api.responses import QuoteResponse

quote = QuoteResponse.from_api({...})

# Option 2: Use domain model
from britecore_sdk.models import Quote

quote = Quote(...)
```

---

### ❌ Deprecated: v1 Endpoint Versions

While v1 endpoints (e.g., `api/api_calls/v1/`) continue to work, they are now considered legacy:

**v1 Endpoints** (still work, not recommended):
- `britecore_sdk.api.api_calls.v1.contacts`
- `britecore_sdk.api.api_calls.v1.policies`
- `britecore_sdk.api.api_calls.v1.quotes`

**v2 Endpoints** (recommended):
- `britecore_sdk.api.api_calls.v2.contacts`
- `britecore_sdk.api.api_calls.v2.policies`
- `britecore_sdk.api.api_calls.v2.quotes`

**Why v2 is better:**
- ✅ Typed response models
- ✅ Better error metadata
- ✅ Consistent parameter naming
- ✅ Future-proof

---

### ❌ Deprecated: Implicit Module-Level Client

**v1.x Pattern** (still works, not recommended):
```python
from britecore_sdk.api.api_calls import init_api_client

init_api_client(target_site="production")
# Implicit global state - hard to test, unclear dependencies
```

**v2.0.0 Pattern** (recommended):
```python
from britecore_sdk import BritecoreAPIClient

client = BritecoreAPIClient("production").init_client()
# Explicit, testable, clear dependencies
```

## Complete v1.x → v2.0.0 Migration Examples

### Example 1: Simple Quote Retrieval

**v1.x (Old):**
```python
from britecore_sdk.api.api_calls import init_api_client
from britecore_sdk.api.api_calls.v2.quotes import get_quote

init_api_client(target_site="production")
quote = get_quote(quote_id="Q123")

premium = quote.get("premium")
```

**v2.0.0 (New):**
```python
from britecore_sdk import BritecoreAPIClient
from britecore_sdk.api.api_calls.v2 import quotes
from britecore_sdk.api.responses import QuoteResponse

with BritecoreAPIClient("production").init_client() as client:
    quote: QuoteResponse = quotes.get_quote(quote_id="Q123", client=client)
    premium = quote.premium  # Type-safe
```

---

### Example 2: List with Pagination

**v1.x (Old):**
```python
from britecore_sdk.api.api_calls import init_api_client
from britecore_sdk.api.api_calls.v2.quotes import list_quotes

init_api_client(target_site="production")

page = 1
all_quotes = []
while True:
    response = list_quotes(page=page, limit=100)
    all_quotes.extend(response["data"])
    if len(response["data"]) < 100:
        break
    page += 1
```

**v2.0.0 (New):**
```python
from britecore_sdk import BritecoreAPIClient
from britecore_sdk.api.iterators import iter_quotes

client = BritecoreAPIClient("production").init_client()

# Automatic pagination
for quote in iter_quotes(client=client):
    process_quote(quote)

# Or collect all
all_quotes = list(iter_quotes(client=client))
```

---

### Example 3: Error Handling

**v1.x (Old):**
```python
from britecore_sdk.api.api_calls import init_api_client
from britecore_sdk.exceptions import NotFoundError

init_api_client(target_site="production")

try:
    quote = get_quote(quote_id="INVALID")
except NotFoundError as e:
    # Limited error context
    print(str(e))
```

**v2.0.0 (New):**
```python
from britecore_sdk import BritecoreAPIClient
from britecore_sdk.exceptions import NotFoundError
import logging

logger = logging.getLogger(__name__)
client = BritecoreAPIClient("production").init_client()

try:
    quote = quotes.get_quote(quote_id="INVALID", client=client)
except NotFoundError as e:
    # Rich error context
    logger.error(
        f"Quote not found: {e.detail}",
        extra={
            "request_id": e.request_id,
            "error_code": e.error_code,
            "status_code": e.status_code,
        }
    )
```

---

### Example 4: Multi-Site Operations

**v1.x (Old):**
```python
from britecore_sdk.api.api_calls import (
    init_api_client,
    reset_api_client,
)

# Site A
client_a = init_api_client(target_site="site_a")
quote_a = get_quote(quote_id="Q1")

reset_api_client()  # Clear state

# Site B
client_b = init_api_client(target_site="site_b")
quote_b = get_quote(quote_id="Q2")
```

**v2.0.0 (New):**
```python
from britecore_sdk import BritecoreAPIClient
from britecore_sdk.api.api_calls.v2 import quotes

# Multiple explicit clients - no state management needed
client_a = BritecoreAPIClient("site_a").init_client()
client_b = BritecoreAPIClient("site_b").init_client()

quote_a = quotes.get_quote(quote_id="Q1", client=client_a)
quote_b = quotes.get_quote(quote_id="Q2", client=client_b)

# Cleanup
client_a.close()
client_b.close()
```

### Example 5: Testing

**v1.x (Old):**
```python
from unittest.mock import patch, MagicMock
from britecore_sdk.api.api_calls import init_api_client
from britecore_sdk.api.api_calls.v2 import quotes

def test_get_quote():
    init_api_client(target_site="test")
    
    # Messy patching of module-level state
    with patch("britecore_sdk.api.api_calls.v2.quotes.API_CLIENT") as mock:
        mock.do_request.return_value = MagicMock()
        mock.process_result.return_value = {"id": "Q1", "premium": 100}
        
        result = quotes.get_quote(quote_id="Q1")
        assert result["premium"] == 100
```

**v2.0.0 (New):**
```python
from unittest.mock import MagicMock
from britecore_sdk import BritecoreAPIClient
from britecore_sdk.api.api_calls.v2 import quotes

def test_get_quote():
    # Create mock client - no global state patching
    mock_client = MagicMock(spec=BritecoreAPIClient)
    mock_client.do_request.return_value = MagicMock()
    mock_client.process_result.return_value = {"id": "Q1", "premium": 100}
    
    result = quotes.get_quote(quote_id="Q1", client=mock_client)
    
    assert result["premium"] == 100
    mock_client.do_request.assert_called_once()
```

## Deprecation Warnings

### What You'll See

When using v1.x patterns, you'll see deprecation warnings:

```
DeprecationWarning: britecore_sdk.classes.Quote is deprecated and will be removed in v3.0.0.
Use britecore_sdk.models.Quote instead.
See docs/migrations/PHASES2-5-FEATURES.md for migration guide.
```

### Controlling Warnings

```python
import warnings

# Show all warnings
warnings.simplefilter("always")

# Suppress specific category
warnings.filterwarnings("ignore", category=DeprecationWarning)

# Turn warnings into errors (recommended for CI)
warnings.simplefilter("error", category=DeprecationWarning)
```

## Migration Checklist

### Step 1: Update Imports
- [ ] Replace `from britecore_sdk.classes import X` with `from britecore_sdk.models import X`
- [ ] Replace `from britecore_sdk.api.api_calls.v1.*` with `from britecore_sdk.api.api_calls.v2.*`
- [ ] Update response handling to use `QuoteResponse`, `PolicyResponse`, etc.

### Step 2: Update Client Initialization
- [ ] Replace `init_api_client(target_site="X")` with `BritecoreAPIClient("X").init_client()`
- [ ] Add `client=client` parameter to all endpoint wrapper calls
- [ ] Use context managers for automatic cleanup

### Step 3: Update Pagination
- [ ] Replace manual pagination loops with `iter_quotes()`, `iter_policies()`, etc.
- [ ] Use Pythonic iterator patterns

### Step 4: Update Error Handling
- [ ] Access `e.status_code`, `e.error_code`, `e.request_id` in exception handlers
- [ ] Update logging to include structured metadata
- [ ] Handle `ValidationError.validation_errors` dict for field-level errors

### Step 5: Add Middleware (Optional)
- [ ] Consider `LoggingMiddleware` for better request logging
- [ ] Consider `RequestIdMiddleware` for correlation tracking
- [ ] Add custom middleware for your use cases (OpenTelemetry, metrics, etc.)

### Step 6: Test & Verify
- [ ] Run full test suite with v2.0.0 code
- [ ] Verify error handling works correctly
- [ ] Test multi-site scenarios if applicable
- [ ] Update test helpers to use explicit client parameter

## Common Migration Issues

### Issue: "classes module not found"

**Error:**
```
ImportError: britecore_sdk.classes.Quote has been removed...
```

**Fix:**
Replace with:
```python
from britecore_sdk.models import Quote
# OR
from britecore_sdk.api.responses import QuoteResponse
```

---

### Issue: "Client not initialized"

**Error:**
```
BritecoreError.ConfigurationError: API client has not been initialized...
```

**Fix:**
Pass explicit `client=` parameter:
```python
# OLD
quote = quotes.get_quote(quote_id="Q1")  # ❌ Implicit client

# NEW
quote = quotes.get_quote(quote_id="Q1", client=client)  # ✅ Explicit
```

---

### Issue: "No attribute 'message' on response"

**Error:**
```
KeyError: 'message'
```

**Fix:**
Use typed response models instead of dict access:
```python
# OLD
message = response["message"]  # May not exist

# NEW
quote = QuoteResponse.from_api(response)
print(quote.quote_number)  # Type-safe
```

## Summary: What Changed

| Aspect | v1.x | v2.0.0 |
|--------|------|--------|
| **Client** | Implicit global | Explicit parameter |
| **Responses** | `Any`/`dict` | Typed models |

| **Extensibility** | Limited | Middleware system |
| **Compatibility** | — | `classes/` removed |
